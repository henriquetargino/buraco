# 🃏 Buraco App

Acesse aqui: [https://buraco.streamlit.app](https://buraco.streamlit.app)

Este é um projeto pessoal criado com muito carinho para modernizar o jogo de baralho **Buraco**, que costumo jogar com a minha mãe.

A ideia surgiu quando percebi que ela estava anotando no bloco de notas, os pontos e as vitórias de cada um. Como gosto de automatizar meu dia a dia, decidi criar esse site para tornar tudo mais prático, visual e divertido.

O aplicativo conta com **dashboards interativos**, **estatísticas em tempo real** e uma aba de **adicionar partida** para computar os pontos de cada um, trazendo mais dinamismo e **aumentando a competitividade** de forma leve e divertida.

Sinta-se à vontade para explorar! 🚀
